# Screenshots

Drop the screenshot images in this folder using these exact names so the
links in the main [README](../README.md) resolve:

| File | Shows |
|---|---|
| `screenshot-feed.png` | The main drop zone / shared items grid |
| `screenshot-screen.png` | The remote screen (VNC) viewer |
| `screenshot-chat.png` | The chat & activity sidebar |

**Tip:** open Dropzone in a desktop browser, resize the window to ~1280px
wide, and use your OS screenshot tool for a clean, consistent shot.
