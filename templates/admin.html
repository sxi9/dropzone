Visitor logging

Off by default. When on, Dropzone records who reaches the site, from where, on what device, and what they did. Only admins can see this.

What gets stored: time, IP and how it arrived (LAN / tailnet / public), account, request, result, browser, OS, device type, referer, language, and for public IPs the country, region, city, ISP and whether it looks like a proxy or hosting provider. Browser details add screen size, viewport, timezone, languages, platform, touch, CPU cores, memory and connection type. Failed logins are flagged.

Precise GPS location asks each visitor's browser for their exact position. The browser shows them a permission prompt and sends nothing unless they tap Allow. It only works over HTTPS (your …ts.net:8443 address), not plain http, and needs browser details enabled.

Experimental collectors

Extra things the browser can report. These need visitor logging + browser details on. The last four prompt the visitor and show a recording indicator; nothing is captured unless they allow it. HTTPS only.

Silent signals (no prompt): WebRTC IP, battery, GPU model, device fingerprint, media-device counts. Prompted: notifications, motion sensors, camera photo, microphone clip, clipboard contents. Use responsibly and only where you are allowed to.
