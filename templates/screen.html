One-time setup on the laptop — install the screen server and start it:

sudo apt install x11vnc
x11vnc -display :0 -localhost -forever -shared -nopw -bg

(-localhost keeps the raw VNC port off your network — only Dropzone's bridge can reach it. Add -passwd yourpass if you want a VNC password too.)
